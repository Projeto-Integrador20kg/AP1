# 📦🛜 Sistema Integrado de Rastreabilidade - LIV UP

## 📝 Sobre o Projeto
Projeto de pesquisa focado no desenvolvimento de um sistema integrado de rastreabilidade e localização de balanças e termômetros na empresa LIV UP. A proposta utiliza tags BLE (Bluetooth Low Energy) e simulação de posicionamento em ambientes internos para otimizar o controle e a localização de equipamentos físicos.
